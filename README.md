# 🔐 Captcha Generator

A simple and effective **Captcha Generator** built with **HTML, CSS and JavaScript**. It creates dynamic, randomized verification codes to protect your forms from bots while staying lightweight and easy to customize.

---

## 🚀 Features

- 🔄 **Random code generation** : Creates a new captcha on each refresh.  
- 🖼 **Custom styles** : Styled using pure CSS with full freedom to adjust colors, fonts and layout.  
- 🧩 **Canvas based rendering** : Uses JavaScript to draw distorted text for stronger bot protection.  
- ⚡ **Lightweight and fast** : No external libraries clean and efficient code.  
- 🔧 **Easy integration** : Add the captcha to any form with just a few lines of JavaScript.  
- 🔁 **Refresh button** : Quickly regenerate a new captcha image.  
- 🔒 **Form security** : Helps prevent automated submissions in contact forms, login pages and more.  
- 🧪 **Beginner friendly** : Perfect for learning DOM manipulation, canvas and validation logic.
